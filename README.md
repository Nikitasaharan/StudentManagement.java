# Student Management System (Java)

## Overview
This is a **menu-driven Student Record Management System** written in Java. It allows users to:
- Add student details (Roll No, Name, Course, Marks)  
- Automatically calculate grades (`A`, `B`, `C`, `D`) based on marks  
- Display all student records in a structured format  

This project demonstrates **Object-Oriented Programming (OOP)** concepts in Java such as Inheritance, Constructors, Methods, Arrays/ArrayList, and Control Structures.


## Features
- **OOP Concepts**: Inheritance, Constructors, Methods  
- **ArrayList**: Manage multiple student records  
- **Methods Implemented**:
  - `inputDetails()` → Add student details  
  - `displayDetails()` → Display student info  
  - `calculateGrade()` → Assign grade based on marks  
- **Menu-based Interaction**: Simple CLI menu with `Scanner`
